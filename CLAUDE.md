# WonderPath

A custom PWA for two kids (Sylvie, 7 and Holland, 4) to explore
topics they're curious about through AI-generated lesson PDFs,
drawing, and a visual curiosity map.

## Stack
- Next.js + Tailwind CSS, deployed on Vercel
- Supabase (Postgres + Storage)
- Claude API (Sonnet for lessons, Haiku for Q&A)
- @react-pdf/renderer for PDF generation
- react-pdf for PDF display
- tldraw for freeform drawing canvas
- Browser SpeechSynthesis API for TTS

## Key Architecture Decisions
- Lessons are structured JSON generated by Claude, rendered into
  PDFs, displayed via react-pdf with a canvas annotation overlay
- Parent reviews each lesson in-person before the child begins
- No auth system — two hardcoded child profiles + a parent dashboard
- No offline support in V1
